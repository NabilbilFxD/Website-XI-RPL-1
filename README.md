# XI RPL 1 Website
Official website for XI RPL 1 (Axioo Class) at SMK Krian 1 Sidoarjo. Built with React, Vite, and Supabase.

## Features
- Dynamic content management (documentation & gallery).
- Student list and organizational structure.
- Industry-aligned insights (Axioo Class & Intel).

## Tech Stack
- Frontend: React 19, Tailwind CSS
- Backend/DB: Supabase
- Build Tool: Vite
